# DataFrameReporter

`DataFrameReporter` помогает быстро проверить таблицу: показывает её размер, количество и долю дубликатов и пропусков, а также основные описательные показатели.

## Установка

Создайте и активируйте виртуальное окружение в Git Bash:

```bash
python -m venv venv
source venv/Scripts/activate
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```
